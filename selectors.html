Different CSS Selectors

This webpage showcases the different kinds of CSS selectors. The usual selectors used are element selectors, ID selectors, and class selectors. For this paragraph, element selector is used.

In this paragraph, ID selector is applied. The ID name is needed to be placed inside the paragraph tag in order to apply the style encloesd in the ID selector.

The last example of selector is class selector which is in this paragraph. There are more types of selectors, such as universal selector, group selector, and attribute selector.
