2nd Quarter Reflection

The lessons in this quarter were a bit challenging. The earlier lessons were fine, but as we progressed, it got harder because there were more and more codes since we were completely using CSS now. It was also hard because we had a lot of big performance tasks, so the teachers couldn't discuss properly since they gave their time for us to do our tasks.

For me, CSS is better than HTML. Although it is more complex and needs more codes, it makes websites look better. We can put CSS codes in a seperate file, and it can help to make our code look cleaner. Personally though, I prefer embedded CSS since I can easily access my codes. But linked CSS is helpful if we want an organized code file.

Even if we haven't discussed a lot this quarter, I still gained new knowledge. With the new codes I have learned, I can make my websites look more presentable. CSS codes are also useful in real life since technology is a big part of our world now.

4th Quarter Reflection

For this quarter, we learned more about JavaScript. The topics were a big step-up compared to HTML and CSS. There were more codes to be learned about and included in activities. Although, you can make better websites using JavaScript.

Even though it can be time-consuming and a little confusing, JavaScript is very helpful. It gives dynamic and creativity to a website. It also gives the user more freedom to create interactive websites.

This quarter was a bit rushed, so it was quite difficult to catch up. But, ICT was alright. You just need to learn about the basic JavaScript codes/functions. Double-checking of codes are also advised since one mistake can lead to a website not loading properly.
